\section{Reproducibility statement}
\label{sec:repro}

Everything reported above regenerates from the public repository. The reported numbers were produced in this environment: Python 3.12.3, numpy 2.5.2, scipy 1.18.1, stim 1.16.0, pymatching 2.4.0, matplotlib 3.11.1 and pytest 9.1.1, with single-threaded linear algebra (\texttt{OPENBLAS\_NUM\_THREADS=1}, \texttt{OMP\_NUM\_THREADS=1}). Each experiment directory records its environment. % F-169
The dependency floors in \texttt{pyproject.toml} are lower bounds, not pins; to reproduce the exact environment, install these versions explicitly. Byte-identity is a property of one fixed environment: across library versions or thread counts, floating-point fields can differ in their final bits even when every reported value and verdict agrees. % F-160, F-161, F-169
Setup and verification:

\begin{verbatim}
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
pip install -e ".[dev]"              # package + pytest
pytest -q                            # 209 tests pass
python -m sbqos.reproduce_all        # nine experiments; manifests verified
python -m sbqos.reproduce_all        # second run; compare byte-for-byte
python paper/figures/make_figures.py # figures F3-F9 (deterministic)
\end{verbatim}

The suite has 188 tests of the prototype and 21 of the paper's figure pipeline. % F-168
The tests that check the theorem anchors are % F-162
\begin{itemize}[nosep]
\item \texttt{test\_thm\_chain\_rule\_rep5\_seeded\_splits\_exact},
\item \texttt{test\_thm\_top\_ladder\_rep3\_mmse\_matches\_bruteforce\_exact},
\item \texttt{test\_thm\_B5\_lumpable\_zero\_deficit\_for\_syndrome\_lens}.
\end{itemize}
Each \texttt{reproduce\_all} run regenerates the nine experiments and verifies the manifest it has just written. The evidence recorded for this paper is stronger: consecutive runs produced byte-identical files, and a fresh run from a clean export of the repository reproduced the committed manifests byte for byte, in about 8 minutes on the reference machine. % F-179
Every experiment directory contains its frozen configuration, results, SHA-256 manifest, environment record and the exact data behind every figure, as CSV. The manifests are committed to the repository, so a reader can confirm that they regenerated the same evidence, not merely similar evidence. % F-149..F-157
