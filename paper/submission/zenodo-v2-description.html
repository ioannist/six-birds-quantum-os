Six Birds Theory (SBT) describes emergence as packaging: a stable macroscopic object arises when microscopic detail is repeatedly coarse-grained and restored to a canonical form. Its central methodological claim is that six primitives (existence certificates, adequacy residuals, predictive quotients, protocol traps, priced budgets, and transport) turn any such packaging structure into concrete computations that can be checked and can fail. This paper tests that claim on quantum error correction, where the packaged object is a logical qubit, in an open, deterministic simulation of small repetition and surface codes. Theorem-level quantities are computed in exact rational arithmetic, and every prediction was registered before its scored run. Of the 25 predictions in the original build, 14 failed; all are reported.

Four primitives nevertheless produced working audit objects. Extended with product features, the adequacy residual attains exactly the minimum mean-squared error with which any estimator can recover the logical observable of the three-qubit repetition code from its syndrome. The existence certificate rejects a decoder that is perfectly stable only because it collapses the logical qubit. Exact memory witnesses separate hidden-state noise from memoryless noise, and a protocol-trap control overturned the study's own registered hypothesis. Every registered prediction about the pricing primitive failed, and transport was not attempted.

The centerpiece is a failed syndrome-only drift detector. It was diagnosed with the framework's own exact machinery, corrected, and re-registered together with a prediction that it would still lose to the baseline on the original test; that prediction held, as did a large predicted win elsewhere. The corrected detector also cleared its registered bar under circuit-level noise, at the narrowest margin the test grid resolves. In a batch-decoded recalibration loop on one channel known to drift, it beat an offline blind schedule matched retrospectively to its number of recalibrations on each seed; whether it beats a schedule with five times its average number of recalibrations is unresolved. The error-correction mechanisms are not new; the contribution is the audit framing, the pre-registration discipline, and a falsification-and-repair loop carried out inside the framework. All code and results are open, and the nine default experiments regenerate byte-identically in the declared environment.
