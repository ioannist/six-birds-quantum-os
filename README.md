# Six Birds Quantum OS (SBQOS)

This repository contains the **quantum-error-correction instantiation** of Six Birds Theory for the paper:

> **Auditing Emergence in Quantum Error Correction: A Falsifiable Instantiation of Six Birds Theory**
>
> Manuscript: `paper/main.pdf` (Preprint v1.0, 5 September 2026)
>
> DOI: https://doi.org/10.5281/zenodo.22337886
>
> Keywords: quantum error correction; emergence; emergence calculus; Six Birds Theory; adequacy residual; existence certificate; pre-registered predictions; drift detection; decoder recalibration; reproducible simulation

The paper tests one methodological claim of Six Birds Theory (SBT): that its abstract primitives (packaging operators, adequacy residuals, existence certificates, predictive quotients, protocol traps, priced budgets) generate concrete, checkable, falsifiable structure when pointed at a real technical domain. The domain is quantum error correction, where the emergent object is a logical qubit. Everything here is classical simulation: stochastic Pauli noise on small stabilizer codes, computed in exact rational arithmetic where the design declares exactness, plus Stim/PyMatching circuit-level sampling for the follow-up experiments.

Predictions were frozen before each experiment was implemented. Of the original build's 25 registered predictions, 14 failed as frozen and are reported unaltered. The paper's centerpiece is a self-correction arc: a registered failure (a syndrome-only drift witness) diagnosed with the framework's own exact machinery, corrected, re-registered with a prediction of continued failure on the original scenario (which held), and carried to circuit-level noise and a closed decoder-recalibration loop.

## What this repository provides

- **Exact moment engine** (`moments.py`): means and covariances of ±1 check/logical observables under independent Pauli noise in `Fraction` arithmetic; Walsh–Hadamard recovery of the full syndrome distribution
- **Adequacy-residual audit** (`xi.py`): the conditional-covariance residual Ξ(D|L), blind-spot witness, chain rule, saturation null, greedy check selection, degree ladder (E1, E3)
- **Existence certificate** (`markov.py`, `closure.py`): idempotence defect δ, retention error ε (δ ≤ ε theorem anchor), closure deficit CD_τ, route mismatch, multiplicity, typed status (E4)
- **Predictive quotients / memory witness** (`quotients.py`): exact current and predictive quotients over a declared history catalog, witnesses, MaxFiber, Δ^max, currentization, minimal machine, protocol-trap internalization (E5)
- **Pricing audit** (`prices.py`): exact value curve, shadow prices, slack point, proxy-cost null (E6; every registered prediction failed, reported as a negative)
- **Drift witnesses** (`streams.py`, `w2_diagnosis.py`, `circuit_level.py`): the original E2 witness, its exact diagnosis, the corrected degree-≤2 quadratic witness with own-null calibration, matched-filter naming, CUSUM wrapper, circuit-level detector-stream version, and the closed recalibration loop (E2, E7, E8, E9)
- **Nine frozen experiments** (`src/sbqos/experiments/`, configs in `src/sbqos/configs/`): seeded, byte-deterministic, SHA-256 manifests, regenerated by one command
- **Frozen design documents** (`design/`): math spec, architecture, registered predictions, controls and claim grades, implementation plan, the follow-up phase, and a public deviations log
- **Paper pipeline** (`paper/`): LaTeX sources, the claim inventory and fact sheet every number traces to, a deterministic figure generator with its specification, and the Zenodo release state

## Scope and limitations

The paper states these fences up front and they bind everything in this repository:

- No quantum hardware; all evidence is classical simulation of stochastic Pauli / classical Markov models and Stim circuit-level sampling
- The residual Ξ is relative to the linear estimator class over the declared probe family; Ξ ≻ 0 does not assert that no nonlinear decoder exists
- No Born-rule, Bell, coherent-dynamics, or asymptotic-threshold claims
- None of the individual QEC mechanisms is claimed as new; the contribution is the audit-and-certificate framing, the pre-registration discipline, and the framework-internal falsification-and-repair loop
- Four of the six SBT primitives produced positively evidenced audit objects; pricing is a full registered negative; transport was scoped out before the build and never implemented


## Install

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

Known-good environment (the versions all reported numbers were measured against): Python 3.10.12, numpy 2.2.6, scipy 1.15.3, stim 1.16.0, pymatching 2.4.0, matplotlib 3.10.8, pytest 9.0.2. See `REPORT.md` §8.

## Test

```bash
pytest -q          # 170 tests: 149 prototype + 21 paper-figure pipeline
```

## Run experiments

```bash
python -m sbqos.reproduce_all   # regenerates all nine experiments and verifies manifests
python -m sbqos.reproduce_all   # run twice: results are byte-identical
```

Outputs land under `artifacts/eN_default/<config-hash>/` (results JSON, CSV data twins, figures, environment record, manifest). Only the manifests are tracked; the artifacts regenerate exactly.

## Build paper

```bash
python paper/figures/make_figures.py      # F3-F9 from the artifact CSVs (byte-deterministic)
cd paper && latexmk -pdf main.tex          # output in paper/build/, copied to paper/main.pdf
```

## Repository layout

- `design/`: frozen design documents (`00_OVERVIEW.md` → `05_IMPLEMENTATION_PLAN.md`, `06_W2_PHASE2.md`, `DEVIATIONS.md`)
- `src/sbqos/`: the prototype package; `experiments/` holds the nine runners, `configs/` their frozen configurations
- `tests/`: the test suite, including brute-force cross-checks for the exact modules and theorem-anchor tests
- `artifacts/`: experiment outputs (regenerated; manifests tracked)
- `REPORT.md`: the prototype report — summary table of every registered prediction, headline and negative results, controls ledger, scope fences, follow-up, reproduction
- `paper/`: manuscript (`main.tex`, `sections/`, `appendices/`), `claims.md`, `facts.md`, `references.bib`, `figures/` (generator, `FIGURE_SPECS.md`, generated images and TikZ sources), `submission/` (Zenodo release state)
